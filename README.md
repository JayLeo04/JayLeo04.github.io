# JayLeo04 Notes

个人博客，发布于 `https://jayleo04.github.io`。内容分为技术、数学和随想，使用 Jekyll 与 GitHub Pages 构建。

## 写第一篇文章

1. 从 `_drafts/` 选择对应模板并复制一份。
2. 将文件移动到 `_posts/`，命名为 `YYYY-MM-DD-title.md`。
3. 分类使用 `tech`、`math` 或 `thoughts`。
4. 提交并推送到 `main` 分支，GitHub Pages 会自动更新。

## 本地预览

```powershell
bundle install
bundle exec jekyll serve
```

然后打开 `http://localhost:4000`。
